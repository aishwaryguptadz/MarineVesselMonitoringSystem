# 🚢 Marine AI Intelligence System

An AI-powered maritime analytics platform that integrates **Machine Learning, Explainable AI, and Backend APIs** to monitor vessel performance, predict fuel efficiency, and analyze operational risks.

---

## 📌 Features

- 🔍 Real-time vessel monitoring
- ⛽ Fuel consumption prediction (ML model)
- 🧠 AI-based query system (/ask endpoint)
- ⚠️ Safety & anomaly detection
- 📊 Engine health monitoring
- 📡 RESTful APIs using FastAPI
- 🗄️ SQL Server database integration

---

## 🚀 How to Run

### 1. Go to backend folder

cd Backend-API (Fast API or Flask) [Shared (integration team)]

 then run server:
uvicorn app:app --reload --host 0.0.0.0 --port 8000

Opne in web:
http://localhost:8000/docs
